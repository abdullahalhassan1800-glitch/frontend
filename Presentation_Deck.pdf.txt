                    1. INTRODUCTION & OVERVIEW
================================================================================

1.1 What is CMS Admin Panel?
   • Web-based management system for online store operations
   • Single dashboard to manage orders, products, customers, and analytics
   • Real-time data synchronization and backup capabilities

1.2 Key Benefits:
   • Centralized management of all business operations
   • Role-based access control for team collaboration
   • Real-time analytics and reporting
   • Automatic data backup 
   • User-friendly interface with minimal training required

1.3 System Requirements:
   • Modern web browser (Chrome, Firefox, Edge, Safari)
   • Internet connection for initial setup and sync
   • No software installation required - browser-based
   • Compatible with desktop, tablet, and mobile devices

                    3. USER ROLES & ACCESS CONTROL
================================================================================

3.1 Role-Based Access System:
   • super_admin: Full system access, user management
   • manager: Operational oversight, read-only users
   • agent: Order creation with restrictions
   • viewer: Dashboards and reports view-only

3.2 Permission Matrix:
   • Module access varies by role
   • Some features restricted based on role level
   • Navigation dynamically shows/hides options
   • Ensures appropriate data access for each team member

3.3 Demo Scenario:
   • Show login with different user roles
   • Demonstrate varying access levels
   • Highlight role-specific features and limitations
